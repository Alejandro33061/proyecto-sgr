# Mockup - Sistema de Gestión de Resultados

## Descripción
Este repositorio contiene el prototipo funcional (Mockup) para el "Sistema de Gestión de Resultados". Su objetivo es demostrar el diseño de interacción, la navegación entre pantallas principales y la validación de formularios de manera frontal (Front-end), sin conexión a base de datos, cumpliendo con la entrega de Análisis y Diseño de Software.

## Tecnologías Utilizadas
* **HTML5:** Estructura de las vistas.
* **CSS3 & Bootstrap 5:** Diseño responsivo, distribución visual y componentes de interfaz (Librería externa).
* **JavaScript (Vanilla):** Lógica de navegación simulada y validación de campos obligatorios.

## Instrucciones de Ejecución
1. Clonar este repositorio en tu máquina local.
2. No se requiere servidor local (Node, Apache, etc.).
3. Simplemente haz doble clic en el archivo `index.html` para abrirlo en cualquier navegador web (Chrome, Firefox, Edge).
4. El flujo inicial comienza en la pantalla de Login. (Puedes ingresar cualquier dato para pasar la validación obligatoria).
